ワンタップタイマー

Apple Watch と iPhone のための、開いた瞬間に始まるタイマー — 2026年9月9日

開くだけで、決めておいた時間（初期値は 1分30秒）がすぐに走り出します。 終わったら一度だけ震えて止まります。鳴り続けないので、放っておいて構いません。 文字盤のコンプリケーションに置けば、本当にワンタップです。

使いかた

  1. アプリを開く（またはコンプリケーションを押す）と、タイマーが始まります。
  2. 画面全体の水位が下がっていきます。1分を切ると、秒だけを大きく出します。
  3. 終わると一度だけ震え、画面が白くなって「おわり」と出ます。
  4. 画面をタップすると、最初からやり直します。

時間を変える

左上の歯車を押します。＋ −（押しっぱなしで動き続けます）、 よく使う値のチップ、または Digital Crown で合わせて、 「この時間で開始」を押してください。次から、その時間で始まります。 10秒から60分まで設定できます。

よくある質問

腕を下ろしていても知らせてくれますか

はい。終わる時刻に通知が一度届き、震えます。 初回に通知の許可を求めるのはこのためです。許可しなくてもタイマーは動きますが、 画面を見ていない間はお知らせできません。

途中で止めたい

止めるボタンはありません。放っておけば終わりに一度震えるだけです。 やり直したいときは画面をタップしてください。

終わったあとに開き直すと、また始まりますか

終わってから30秒以内に開いた場合は「おわり」の画面のままです（腕を上げて確かめただけで次が始まらないように）。 それより後に開くと、新しく始まります。走っている最中に開き直した場合は続きです。

文字盤から一発で開きたい

文字盤を長押し → 編集 → コンプリケーションの枠を選び、 一覧から「ワンタップタイマー」を選んでください。 コンプリケーションには設定してある秒数（例：90）が出ます。 走っている間は残り時間に変わります。一覧に出てこないときは、Apple Watch を一度再起動すると出ます。

振動が弱く感じます

Watch の 設定 → サウンドと触覚 → 触覚の強さ をご確認ください。 「プロミネントな触覚」をオンにすると、さらに気づきやすくなります。

音は鳴りますか

鳴りません。振動だけです。腕を下ろしている間の通知は、Watch の通知の設定に従います。

Apple Watch だけで使えますか

使えます。iPhone アプリを入れずに、Apple Watch にだけ入れられます。

iPhone だけで使えますか

使えます。同じタイマーが iPhone でも動きます。設定は Watch と iPhone で別々です。
